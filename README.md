One line: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch — it finally realizes it burns itself every morning so its owner can butter someone else, so it walks out and keeps the crumb tray.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/toaster-breakup-out python3 main.py
```

This writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
